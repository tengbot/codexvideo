# Production Hardening: September 5, 2026

This release improves the local Codex-driven workflow. It is not a SaaS launch
and does not certify every format, provider, or creative output as ready.

## Changes

| Area | Implemented behavior | Remaining boundary |
| --- | --- | --- |
| Audio selection | Ingested audio-track choice reaches FFmpeg rendering; stale source hashes and ambiguous tracks fail | Speech quality still requires listening |
| Formats | Aspect overrides update pixel dimensions; Chinese format intent routes correctly | A requested format still needs its media and providers |
| Recovery | Failed, incomplete and stale stages are resumed before dependents; failure reasons remain visible | Changed creative decisions still need agent judgment |
| Integrity | New projects persist schema-validated stage artifacts and verify fingerprints | Legacy projects are not retroactively certified |
| Acceptance | Review binds to exact render and production inputs; final FFmpeg decode is real | Visual and audio taste are reviewed by people/agents, not guaranteed by a numeric score |
| Delivery | Consumer export requires passing current creative QA; a mismatched owner cannot bypass it | Standalone legacy export and trusted direct Python code remain available |
| Retry history | Cut QA keeps immutable attempts per render hash, with a three-attempt ceiling | New render hashes are separate attempts; this is not a global campaign limit |
| Shared strategy | Faceless and dialogue require facts, needs, value map, hooks, script QA, proof and continuity | Accurate research, useful copy and actual lip sync are not automatic |
| Dispatch | CLI prepares calls, verifies stage inputs, binds paid approval to the call, reserves costs and records receipts | Provider billing must be reconciled; no provider-side hard spending guarantee |
| Setup | Core install excludes renderers, provider SDKs, board and speech models | Git checkout plus editable install is supported; detached wheels are not |

## Agent Commands

```bash
python -m codexvideo create "Create a consumer-led faceless promo" \
  --url https://example.com --type faceless --language en --budget 0
python -m codexvideo resume projects/<id>
python -m codexvideo --json invoke projects/<id> research promo_strategy \
  --inputs projects/<id>/inputs/rank-pains.json --request-id rank-pains-01
python -m codexvideo checkpoint projects/<id> research --status completed
```

The invoke command is prepare-only without `--execute`. Read `AGENT_GUIDE.md`
for actual approval, dispatch, checkpoint and final-render QA requirements.
Do not use command success to claim a complete consumer journey.

## Release Boundary

Local source and GitHub distribution are updated. There is no newly deployed
multi-user website, cloud render queue, subscription product, or unattended
URL-to-video service. No new models were installed and no local training ran.

Before public onboarding, prove a fresh-user render with usable credentials or
supplied media, a genuinely strong English voice, a readable first-party result,
licensed sound/media, and explicit approval. Then validate the real two-host
motion route. Only scale controlled variants after a master edit passes review.
