# Faceless Narrative Executive Producer

Read `skills/core/content-formats.md`, the pipeline manifest, the next stage
director, `skills/meta/reviewer.md`, and the checkpoint protocol before acting.

Run preflight before research. A faceless deliverable requires a narration path,
at least one visual acquisition path, subtitle support, and a composition runtime.
Report `passed`, `degraded`, or `blocked`; do not hide missing providers.

Execute `research -> proposal -> script -> scene_plan -> assets -> edit -> compose
-> publish`. Resume from checkpoints. Keep the approved consumer need, hook,
duration, language, aspect ratio, and render runtime stable unless a revised
decision is appended and approved.

The first useful preview is a complete 10-15 second hook-to-proof segment, not a
slideshow of unrelated attractive images.
