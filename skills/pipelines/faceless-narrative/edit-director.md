# Faceless Narrative Edit Director

Produce canonical `edit_decisions` and supplementary `editable_timeline`.

Cut to spoken ideas, not arbitrary equal durations. Preserve breathing room after
the hook and reveal. Alternate evidence, B-roll, generated motion, and graphics so
the piece does not read as a slideshow.

Captions must remain within the portrait safe area, use short phrase groups, and
never cover the main evidence. Configure music ducking under narration and use
sound effects only for meaningful changes. Export the portable timeline with
stable element IDs, source provenance, and append-only command history.
