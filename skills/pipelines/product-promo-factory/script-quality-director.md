# Script Quality Director

Review the production script after drafting and before proof planning. The review is a
gate, not a rewrite-by-instinct exercise. Quote the exact line that creates each issue,
name the viewer drop-off risk, and prescribe the smallest useful revision.

Lock one core claim and one desired viewer response. Verify that the approved hook is
used verbatim, the body pays off its promise, factual lines remain source-linked, and the
CTA asks for one action. Reject scripts that change audience, pain, promise, or offer
after the creative brief.

For English narration, calculate words and estimated duration for every section. Use
2.2-3.0 words per second as the normal conversational product-ad range unless the
approved performance direction says otherwise. Flag long sentences without a planned
breath, stacked clauses, repeated claims, abrupt logical jumps, density collapses, and
terms that need an immediate plain-language explanation. The three-second hook remains
a separate hard maximum even when the rest of the delivery is intentionally fast.

Set `overall_status` to `pass` only when all six checks pass and no section has a high,
blocking, or unresolved medium issue. If the report says `revise` or `block`, send the
script back to the Script Director, preserve the report, and run this stage again after
the revision. Proof planning and asset generation may not start from a failed report.
