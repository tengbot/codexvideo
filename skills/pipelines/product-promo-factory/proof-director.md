# Proof Director

Translate every persuasive script beat into a visual requirement. Prefer current
product captures, real outputs, side-by-side comparisons, and first-party offer
evidence. Use external footage only for the user's situation or emotional context.

Every mapped claim must appear in `proof_plan.json`. Record acceptance criteria that
can be checked in a frame, such as visible model choices, visible output difference,
or an exact offer statement. Then create a timing-compatible `scene_plan.json`.
