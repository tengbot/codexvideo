# Script Director

Write concise spoken copy in the market language. Use the approved hook verbatim,
then explain the solution, show proof, and end with one action. Do not insert a brand
history, feature inventory, or unsupported superlative.

For a 15-second cut, target hook 0-3, solution 3-9, proof 9-13, CTA 13-15. For a
30-second cut, target hook 0-3, pain consequence 3-7, solution 7-17, proof 17-25,
CTA 25-30. Every factual line carries a product-truth source reference.
