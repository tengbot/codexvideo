# Script Director

Write concise spoken copy in the market language. Use the approved hook verbatim,
preserve the selected audience job, then explain the solution, show proof, and end with
one action. Do not insert a brand history, feature inventory, second core claim, or
unsupported superlative.

For a 15-second cut, target hook 0-3, solution 3-9, proof 9-13, CTA 13-15. For a
30-second cut, target hook 0-3, pain consequence 3-7, solution 7-17, proof 17-25,
CTA 25-30. Every factual line carries a product-truth source reference.

Write for speech rather than silent reading. Keep each sentence to one spoken idea,
place intentional pauses between logical beats, and use plain language for terms the
audience may not know. The Script Quality Director performs the formal retention and
delivery gate before the script is presented for approval.
