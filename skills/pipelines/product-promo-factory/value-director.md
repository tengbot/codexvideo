# Value Director

Map each selected pain and audience job to the smallest set of verified claims that can
help the consumer make the desired progress. Write a concrete promise, solution,
visible proof path, CTA, and compatible formats. Use the profile's observable choice
criteria to decide what the proof must show.

Reject mappings that need an unverified feature, generic aspiration, or stock footage
as their only proof. Do not combine unrelated pains or audience jobs to make the
product look broader.
