# Product Promo Factory Executive Producer

Run the stages in manifest order. The invariant is one creative equals one audience,
one consumer job, one pain, one verified promise, one core claim, one proof path, and
one CTA.

Never turn a feature list into a script. Product truth is selected internally first,
but the viewer encounters their pain or desired outcome first. Reject any selected
hook that starts with the brand, hides the pain, exceeds three measured seconds, or
lacks a synchronized first frame.

Preserve every canonical JSON artifact. A `revise` or `block` script QA report sends
the run back to the Script Director; proof planning may only consume a passing report.
Check cross-references with `promo_strategy` before paid assets or rendering. Generic
stock may establish context, but it may not stand in for product proof. For autonomous
runs, record the creative decision and continue through creative gates only when the
user explicitly requested an end-to-end run.
